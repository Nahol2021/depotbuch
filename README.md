# Depotbuch

Team-Übersicht für das Planspiel Börse 2026: Depot, Termine mit Szenarien, Tagesbericht und Notizen.

- Anschauen: ohne Anmeldung über GitHub Pages.
- Eintragen: auf der Seite unter „Schreibzugang“ einen GitHub-Token (classic, Scope `public_repo`) speichern. Das Konto muss Mitarbeiter im Repository sein.
- Daten liegen in `data/*.json`. Kurse, Termine und Tagesbericht werden per Commit aktualisiert.

Spielgeld, keine Anlageberatung.
