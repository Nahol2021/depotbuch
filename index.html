Schreibzugang

Eintragen ist auf diesem Gerät freigeschaltet.

Anschauen geht ohne Anmeldung. Zum Eintragen braucht jedes Gerät einmal einen GitHub-Schlüssel (Token). Der Schlüssel bleibt nur in diesem Browser gespeichert.

So bekommst du einen Schlüssel
  1. Bei GitHub anmelden. Dein Konto muss als Mitarbeiter (Collaborator) im Repository Nahol2021/depotbuch eingetragen sein.
  2. Öffne github.com/settings/tokens/new.
  3. Bei „Note“ steht schon „Depotbuch“. Bei „Expiration“ z. B. „Custom“ und den 31.01.2027 wählen.
  4. Nur das Häkchen public_repo setzen (ist schon gesetzt), ganz unten „Generate token“.
  5. Den Schlüssel (beginnt mit ghp_) kopieren und hier einfügen.
